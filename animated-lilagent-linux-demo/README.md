# Animated Lil Agent — Linux Desktop Demo

A Linux port of the [ryanstephen/lil-agents](https://github.com/ryanstephen/lil-agents)
animated character desktop overlay, adapted for **Arch Linux · KDE Plasma · X11**.

An animated character walks across the bottom of your screen, above the panel/dock.
Click the character to open a native greeting dialog.
Clicks on transparent (background) pixels pass straight through to whatever is underneath.

---

## Features

| Feature | Details |
|---------|---------|
| Transparent overlay | `Qt.WA_TranslucentBackground` + borderless window |
| Always on top | `Qt.WindowStaysOnTopHint` + `Qt.X11BypassWindowManagerHint` |
| Click-through transparency | Per-frame alpha mask via `QWidget.setMask()` |
| Walk animation | Timer-driven frame cycling + horizontal window movement |
| Click popover | Native `QDialog` shown when the character body is clicked |
| Video support | GStreamer pipeline (VP9+alpha WebM, HEVC+alpha MOV/MKV) |
| PNG fallback | RGBA PNG frame sequences — no codec needed |

## Requirements

### Arch Linux (core)

```bash
sudo pacman -S python python-pyqt5 python-pillow
```

### Optional — GStreamer transparent video playback

Required only if you want to play `.mov` / `.webm` / `.mkv` video files with
an alpha channel instead of PNG frames.

```bash
# Core GStreamer runtime + Python bindings
sudo pacman -S gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad \
               python-gobject gst-python

# For HEVC/H.265 with alpha (.mov from macOS lil-agents)
# gst-libav is in the Arch extra repository:
sudo pacman -S gst-libav
```

> **Royalty-free alternative:** Convert assets to VP9+alpha `.webm` — see the
> [Convert macOS .mov to WebM](#convert-macos-mov-to-webm-ffmpeg) section below.
> VP9 support is in `gst-plugins-good` and requires no non-free codecs.

## Quick Start

```bash
cd animated-lilagent-linux-demo

# 1. Generate the demo walk-cycle PNG frames (requires python-pillow)
python create_assets.py

# 2. Launch the overlay
python lil_agent.py
```

The character will appear at the bottom of your screen and start walking.
**Click it** to open the greeting dialog.  Press **Ctrl+C** in the terminal to quit.

## Using Your Own Animation

### PNG Frame Sequence (recommended — no codec dependencies)

Place your own RGBA PNG frames in the `assets/` folder, named sequentially:

```
assets/walk_00.png
assets/walk_01.png
...
assets/walk_07.png
```

Requirements:
- Images **must have an alpha channel** (RGBA / 32-bit PNG)
- Frame size can be anything; the window is sized to match `walk_00.png`
- Transparent pixels are automatically click-through

### Transparent Video (GStreamer required)

Place a transparent video file in the `assets/` directory.
Supported formats and recommended settings:

| Container | Codec      | Alpha support | GStreamer plugin      |
|-----------|------------|---------------|-----------------------|
| `.webm`   | VP9+alpha  | ✅ free        | `gst-plugins-good`   |
| `.mov`    | HEVC+alpha | ✅ (non-free)  | `gst-libav`          |
| `.mkv`    | VP8+alpha  | ✅ free        | `gst-plugins-good`   |
| `.mp4`    | H.264      | ❌ no alpha    | —                    |

#### Convert macOS .mov to WebM (FFmpeg)

```bash
# Install FFmpeg
sudo pacman -S ffmpeg

# Convert transparent HEVC .mov → transparent VP9 WebM (free codec)
ffmpeg -i walk-bruce-01.mov \
       -c:v libvpx-vp9 -pix_fmt yuva420p \
       -b:v 0 -crf 33 \
       assets/walk_character.webm
```

## Configuration

Edit these constants at the top of `lil_agent.py` to customise behaviour:

| Constant        | Default | Description                                              |
|-----------------|---------|----------------------------------------------------------|
| `PANEL_HEIGHT`  | `48`    | Pixels above the bottom edge (standard KDE panel height) |
| `WALK_SPEED`    | `4`     | Pixels moved per tick — controls walk pace               |
| `ANIMATION_FPS` | `12`    | Walk-cycle frame rate                                    |

### Code architecture

```
lil_agent.py
├── FrameSource          loads PNG frames or extracts video frames via GStreamer
│   ├── _try_png_sequence()    walk_*.png in assets/
│   ├── _try_gst_video()       GStreamer appsink pipeline → QPixmap list
│   └── _make_placeholder()    built-in coloured-rectangle fallback
├── CharacterWindow      transparent Qt overlay window
│   ├── _setup_window()        configure Qt flags + attributes
│   ├── _begin_walk()          reposition at screen edge, random direction
│   ├── _on_walk_tick()        move window ~60 Hz
│   ├── _on_anim_tick()        advance frame at ANIMATION_FPS
│   ├── _refresh_frame()       mirror + build alpha mask + repaint
│   └── mousePressEvent()      open GreetingDialog on character click
└── GreetingDialog       native QDialog shown on click
```

## Platform Notes

### KDE Plasma / X11

`Qt.X11BypassWindowManagerHint` is used to create a window that truly floats
above KWin and the KDE panel.  This is the most reliable approach for desktop
overlay widgets on X11.  As a side effect:

- The window does not appear in the taskbar or Alt-Tab switcher (`Qt.Tool`).
- KWin cannot minimise or move the window.
- The window is visible on all virtual desktops.

If you prefer to have the character managed by KWin (e.g. to pin it to one
desktop), remove `Qt.X11BypassWindowManagerHint` from the `_setup_window()`
flags in `lil_agent.py`.  The character will still be always-on-top of normal
windows but may appear below the KDE panel.

### Wayland

Wayland is **not supported**.  Wayland's security model does not allow
arbitrary window positioning or always-on-top overlays from unprivileged
clients.  To use this demo, run an X11 session or enable XWayland and launch
with `DISPLAY=:0 python lil_agent.py`.

### Multi-monitor

The character walks across the **primary screen** (as reported by Qt).  To
target a different screen, change `app.primaryScreen()` in `main()` to
`app.screens()[n]` for monitor index `n`.

## Troubleshooting

**Character does not appear**
- Ensure compositing is enabled: *KDE System Settings → Display → Compositor*
- Try removing `Qt.X11BypassWindowManagerHint` from the flags and re-running.

**Character appears as a solid rectangle (no transparency)**
- Compositing must be active for `Qt.WA_TranslucentBackground` to work.
- Check `kwin --replace &` to restart the compositor.

**Clicks fall through even on the character body**
- Confirm the PNG files have an alpha channel: `file assets/walk_00.png`
  should say *8-bit/color RGBA*.
- Re-run `python create_assets.py` to regenerate frames.

**Video won't load / GStreamer error**
- Check available elements: `gst-inspect-1.0 vp9dec`
- Fallback: generate PNG frames with `python create_assets.py` instead.

**`ModuleNotFoundError: No module named 'PyQt5'`**
```bash
sudo pacman -S python-pyqt5
```
